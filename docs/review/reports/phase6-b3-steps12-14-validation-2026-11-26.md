# Phase 6 第 12–14 项 B3 隔离验收

> 范围为单实例、单监控类型、单订阅规则上的合成工单、清单写入和只读任务。实施分工、原候选记录和本轮接续计划见[实施与验收计划](../../planning/phase6-steps12-14-b3-plan.md)。

## 候选与专项

- 从四仓远端 main 固定来源，Core `9d0019b7`、Taskrunner `30b839af`、ActiveList `d2fd4553`、UI `7da903fe`。将已核对的 B3 改动复制到四仓独立验证分支。以下实际联动使用 Core `6fde79264990…`、ActiveList `38562cce417f…` 和 Taskrunner `80266ec60854…` 的二进制制品。
- 兄弟仓验证分支的本地提交为 Taskrunner `531dd2f`、ActiveList `5758ea6` 和 UI `d832053b`。
- **第 12 项**。实际 Core 发布并执行合成流转，丢失首次流转回包后从原请求键读回。Taskrunner 重启以后，报告回原节点和修订，工单可继续处于后续节点。停用操作者后待执行任务被阻止。另用真实 PostgreSQL 连续八次验证失去原流转职责及职责保留两个分支。Chromium 经实际登录在原单看到报告、原版本和任务号，键盘刷新触发 Core 详情读取。
- **第 13 项**。实际 Taskrunner 按指定资格更新指定清单行和字段。两条同版本任务只产生一笔提交，另一笔得到版本冲突。越权行、禁改字段和执行前撤权不产生部分写入。真实 PostgreSQL 中的同号重放和写回执失败用例相应保留原效果或整体回滚。
- **第 14 项**。三个直接清单变化各派生一个原号任务。首个 ACK 在 Core 提交后丢失，ActiveList 和 Core 强制重启后复用原收件、操作和任务号。两个任务成功观察，第三个因执行前撤权而被阻止。两次成功的事件版本分别为 1、2，观察版本均为 2。查询期间清单业务记录版本不变，写回执计数为 0。
- **联动复验**。工单驱动的 Taskrunner 更新提交后，按该次更新的原操作号查得一条 ActiveList 源事实和一个成功的只读后继任务。后继观察版本及字段与该次提交一致，清单写回执仍只有原更新一条。
- **权限和升级**。旧清单入口用一致的 404 保护越权行和缺失行。受监控类型的唯一键冲突返回通用 409，旧元数据列表、总数、详情和历史遵守同一边界。真实旧 v2 库中的三个合法同名动态类型及原记录升级至 v4 后均保留。B3 空库往返通过，带数据回滚按预期拒绝。

## 普通档门禁

- Core 的 lint、单测、覆盖率、Swagger 生成和 `make migrate-up` 通过。单测语句覆盖率为 21.0%，本轮没有采集基线覆盖率。`make acceptance` 退出 0，四阶段分别通过 123、68、26、35 项，显式跳过为 0。99 对迁移往返内容零漂移。源码和二进制漏洞扫描均通过。
- Core 单次 `make test-integration` 因账户服务的 15 分钟包级超时和模拟目录包的 Docker 清理进程竞争退出非零。同一候选的账户服务首跑通过 228 个顶层用例，续跑通过其余 22 个。模拟目录整包独立重跑通过。原跑和补跑合计覆盖全部 45 个集成包，显式跳过为 0。
- Taskrunner 的 lint、单测、构建、专属 PostgreSQL 和 Redis 的竞态测试，以及源码和二进制扫描均通过。含 cron 的动态端口 E2E 通过 23 项，临时适配限于端口和资源名，使用合成回调。实际 B3 业务效果由三条隔离联动验收覆盖。
- ActiveList 的 lint、单测、构建、竞态和源码及二进制扫描均通过。最终原磁盘夹具逐包跑完真实 PostgreSQL 集成，其中服务包通过 46 项。首次出现 PostgreSQL 启动超时和 Ryuk 清理竞争，单独进程重跑通过。另有仅调整测试数据库存储介质的 tmpfs 对照组，未改生产代码。现有 Testcontainers 链路的 OpenTelemetry 传递依赖锁定为 1.47.0，`otel/log` 从该测试依赖链进入。
- UI 的 lint、类型检查、生产依赖审计和构建通过，79 个单测文件共 1163 项通过。最终四组件 Playwright 通过 55 项，显式跳过及重试均为 0。此前分别遇到专属栈 Core 单例锁失联和 S16 合成账号用户名与标准夹具不符，重建最终 AL 的独立数据库并按标准 global setup 收敛账号后完整通过。

## 本批边界

原工单详情最多展示最近 50 条任务结果，较早结果的按号入口或分页尚未交付。直接清单写入的验收使用签名生产者 API，授权浏览器直写和同操作重放另行验证。多实例滚动启用、在线订阅换版及真实无人值守授权沿各自批准范围验收。
