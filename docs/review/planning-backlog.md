# 全项目排期与遗留处置总账

日期：2026-11-11。状态：本轮规划落档，全部工作项均未因登记而视为实现。本账是当前跨仓工作项、去重估算和处理窗口的入口；具体字段以[机器总账](planning-backlog.json)为权威，本页表格为其阅读投影并同步校验。阶段稿保留详细合同与历史来源，不维护另一套总工期。

## 1. 怎样读这份排期

本账将旧挂账、历史比较建议、新审查与用户需求归并为 **67个工作包**；[来源映射](planning-source-map.json)含 **501个来源条目**，包括历史评审81条、比较30项、Phase6触发索引116行、26件工单设计及本轮发现。来源条目含重复、交叉引用和已关闭历史，不能当501项新需求或缺陷。

每个来源均有唯一主工作包，复合来源另标related_work_items；估算只在主工作包维护一次，已关闭项仅保留回归，不能重新计工。原建议与本轮供给优先原则冲突时，以当前工作包出口为准，例如IOC权威清单改为消费TIP，通用DAG/强制SOAR迁回改为退出裁决。

**排期单位是有先后和出口的实施波次，尚不是日历承诺。** T0为后续实际实施启动，投入和每波冻结范围未定；不沿用旧6–8/13–16周或2027–2028日历。下列工作日区间是单包设计、增量实施与适用验证的粗估，外部等待单列，波次开工前按差异复估。批次顺序与决策截止有约束；不能将所有包上限相加再称为当前工期，也不能把Agent并行等同无限人力。

每包责任为角色/归属仓，具体agent与人名在实施任务中绑定。依赖是交付依赖；外部契约调查和mock可以先行，不必等待对应提供方上线。所有生产/真实集成放行按能力分别验收。
