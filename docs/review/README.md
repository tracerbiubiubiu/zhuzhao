# 审查与项目控制

> 用途：核实当前实现、复验结论和追溯历史。当前计划统一进入[planning](../planning/README.md)，本目录保存控制台、审查方法和正式报告。

## 核实当前状态

[项目控制台](11-project-control.md)列出现在可以用的功能、还没修的问题和数据库迁移编号。查一项功能时，分别确认设计是否获批、代码是否合入、哪版通过测试，以及是否已部署。旧报告中的通过结果仅适用于报告所列版本，新候选要按当前要求重新验证。

开工前先查这次要做什么、还有什么没确定、估算多少工日，再按工作包找到设计和交接。准备试用或上线时，查该工作包适用的条件。 [规划入口](../planning/README.md) · [按工作包查设计](../planning/README.md#按工作包找合同与交接)

- [工作资料库](../toolkit/README.md)：统一方法索引、空白模板及开发/审计提示词；原件与执行实例分开保存。

- [正式报告索引](reports/README.md)：按准确日期、源码/制品/环境与结果复核。报告保留原hash、首次失败、重试、NOT_RUN及运行限制，后继结论通过链接说明。
