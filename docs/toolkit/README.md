# 工作资料库

> 用途：查找可复用的协作方法、空白模板和开发提示词；读者：维护者与协作方。范围：五仓开发/审计工作资料；状态：文档工具已整理，不代表任何执行实例或业务能力已通过验证。权威：分类与Git规则见[文档维护约定](../documentation.md#6-可复用工作资料与执行生命周期)，操作权限与门禁仍遵各仓AGENTS及[工程公约](../standards.md)。

- [方法与流程](playbooks/README.md)：先读适用范围、步骤、检查维度与出口；现有方法保留其唯一正文。
- [空白模板](templates/README.md)：复制结构到本轮执行实例，原件只维护字段和说明。
- [开发与审计提示词](prompts/README.md)：填写范围等输入后启动/接续工作，不默认授予写代码、提交、推送或环境操作权限。

首次审计先读方法，再填写执行卡，按需使用提示词，正式结论采用报告模板；修复须按当前授权进入独立批次，并按复验模板记录结果。

可复用原件随Git；执行实例按内容分别进入review/reports或本地批次。原日志、截图、调研原件和过程收据见[材料目录](../materials.md)，不回填模板。业务运行时提示词/模板、源码参考技能、生成输入和测试夹具留在实际消费者要求的位置。

工具识别位置的例外：本仓[PR模板](../../.github/pull_request_template.md)由GitHub读取，继续在.github维护。后续增加Issue模板/技能等固定位置文件时，在此索引其实际路径，不复制正文或提前建立空目录。
