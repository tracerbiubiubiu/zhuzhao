# 审计启动与接续提示词

> 用途：在已明确的任务边界内启动或接续审计；读者：维护者与审计协作方。输入：下方占位信息、当前授权及执行卡；输出：覆盖/发现/证据与下一步。状态：提示词原件，复制和发送不代表已执行。权威：[审计方法](../../review/audit-playbook.md)、各仓AGENTS及当前会话指示。

在项目仓库内读取原件后，将下面正文复制到任务中并填写占位符。跨环境使用时提供相应权威文件；输入不全如实记录限制。长期报告与本地过程材料的去向按[文档规则](../../documentation.md#6-可复用工作资料与执行生命周期)判断。

```text
请按项目AGENTS、docs/documentation.md与docs/review/audit-playbook.md执行本次审计。

审计类型与目标：<全量/阶段/专项/复审；要回答的问题>
纳入范围与明确排除项：<仓库、模块、场景、当前交付及未来参照>
候选基线：<各仓完整SHA或待核的明确分支；增量起止；工作区改动处理>
当前允许操作与禁止项：<沿用当前会话授权，不从此原件推导写代码/提交/推送/环境操作权限>
执行卡与证据批次：<轮次ID、已有执行卡；本地工作区与归档材料ID>
可用隔离环境及限制：<实际产物来源、资源属主、允许测试、不可用项>

先核对实际仓库/依赖/运行产物和授权；未知条件记待确认及影响，继续不依赖它的工作。
根据执行卡模板建立或更新本地实例，按方法阶段检查设计、实现、实际消费者及证据。
逐项区分确认缺陷、待验证假设、文档漂移、已接受取舍和未来前置；不把未来未实现自动判作当前缺陷。
保留首次失败、重试、skip与未运行边界；报告按模板填写，不从历史绿色推出新候选通过。
收尾复核全部受审仓最新差集，明确结论截止；正式结论与本地原材料按规则分别保存，给出残留项和下一步。

若是接续任务：先读执行卡、最新报告、覆盖台账与在途记录，核对新增差集后继续未覆盖项。
若需修复或扩大操作：先核当前授权；超出范围的动作只给具体建议，不从本提示词扩大授权。
```
