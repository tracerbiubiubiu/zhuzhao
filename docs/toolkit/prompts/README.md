# 开发与审计提示词

> 用途：复用任务表达与接续输入；读者：维护者。范围：人工开发/审计协作，不含产品运行时系统提示词。状态：可填写的原件，不构成执行授权或审计结果。权威：当前用户指示、各仓AGENTS、[工程公约](../../standards.md)与[文档维护约定](../../documentation.md)。

[审计启动与接续](audit.md)配合[审计方法](../../review/audit-playbook.md)和[执行卡](../templates/audit-execution-card.md)使用。复制后填明确范围、准确版本和允许操作；省略输入写待确认，不能默认补出权限。方法与门禁只链接权威来源，提示词不另设一套规则。

[智能体角色与并行派单](agent-roles.md)提供共用底稿、角色提示词、工作树与资源边界，以及派单和交回样式；审计角色继续复用上面的启动入口。

本目录维护可复用原件；发送过的提示词、会话内容、真实基线及执行记录属于本地批次。若提示词将来由产品或测试实际加载，转由相应消费者管理并执行其门禁，不能以Markdown或位于docs为由降档。
