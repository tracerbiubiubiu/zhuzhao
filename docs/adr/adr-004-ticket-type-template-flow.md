# ADR-004: 工单类型 / 模板 / 流程三者关系 —— 维持单向（类型为根，模板为预填预设）

## 日期
2026-10-27

## 状态
已采纳（[Phase 6 流程引擎设计](../phase6/00-flow-engine-v2.md) §5 决策点 2，所有者于 2026-10-27 选择方案 A）。本页确认三者的归属关系；不据此认定定义快照或模板选择界面已经交付。背景中的实现状态保留在决策当时，后续进度见对应阶段文档。

## 背景
- Phase 6 启动段 P6-R0（流程引擎 v2）计划交付出边条件构建器（B0-5）与定义快照版本化（B0-3）。首先要确定条件表达式能选择哪份字段定义（schema），以及快照按什么单位保存、固定哪些定义；这些都取决于类型 / 模板 / 流程三者的归属关系。
- 现状（代码级）：`ticket_types` 持 states / transitions / transition_meta（流程定义），`ticket_type_fields` 持字段 schema（含 `field_meta`：formula / visible_when / fetch / 布局）；`ticket_templates` 有 `type_code` 外键与 default_fields / default_priority / default_sla_minutes、org 隔离——**模板不持表单 schema、不持流程**，是类型下的发单预填预设。`CreateTicketInput.template_code` 后端已实现、前端发起页未接（03 号 §2 缺口①）。
- 三方对标（2026-10-27 代码级盘点）：eflow（ecmdb 体系）用 form-create 模板 ↔ workflow **双向引用**（B 形态）；ficus-oa 流程持 formId + 节点级表单（A 形态）。

## 决策
**A：维持单向。** 本页的 A 指“类型持有字段和流程，模板只提供预填值”；B 指“模板与流程作为独立资源，建立可复用的双向引用”。

- 类型 = 字段 schema + 流程定义的**根**；模板 = 类型下的预填预设（org 隔离），**不升为独立资源**；流程**不脱离类型**成为跨类型复用的工件。
- 条件构建器（B0-5）的条件左值从同类型的字段定义中选择；定义快照（B0-3）以类型为单位、**包含字段定义**（00 号拍板点 5）。
- 模板选择的前端接入随 [工单能力补齐计划](../phase6/06-ticket-completeness.md) B2 批次（既有登记缺口①，零契约变更）。

例如，“设备申领”类型定义申请字段和审批流程；“新员工入职”模板可以预填设备种类与优先级。选择模板只改变初始值，不会为这张工单另建一套字段定义或审批流程。

## 理由
- **与服务台 / OA 主流采用相近的归属关系**：ServiceNow（表为根、字段即列、`sys_template` 预填、Flow 挂表）、钉钉 / 飞书审批（审批模板 = 表单 + 流程 + 可见范围一体）、ficus-oa。
- **本项目的配置维护取舍**：B能跨类型复用流程与表单，也会增加配置引用维护和变更影响分析。当前没有“同一流程被多表单复用”或“同一表单服务多类型”的真实需求，优先维持类型为根的A；复用需求出现时再按[00号拍板点2](../phase6/00-flow-engine-v2.md#5-启动拍板点)评估B。
- **eflow 的双向引用有前提**：form-create 表单天然是独立产品；zhuzhao 没有这个前提，字段本就归类型。
- **零迁移**：A 不动任何表；B 需模板升独立资源、流程独立成表、全部 transition_meta / 字段引用改绑。
- **方案 B 中两项与 A 兼容的能力已另行纳入设计**：Jira Transition Screen（转换时弹字段）= 06 号件 1「转换时字段采集」；ServiceNow UI Policy（按状态控字段可见 / 必填）= P2「状态级字段权限矩阵」。

## 后果
- 正面：确定了 B0-3 / B0-4 / B0-5 应引用的定义；快照以类型为单位并包含字段定义，进行中的工单按自身绑定的版本显示与校验；模板接入的改动规模较小。
- 负面 / 风险：同一流程要在多个类型间复用时需各自配置——由 06 号件 7（类型定义包导入导出）与 P2 类型克隆缓解。
- **重新评估条件**：出现「同一流程被多个表单复用」或「同一表单服务多个类型」的真实诉求时重评 B；届时迁移路径 = 模板升独立资源 + 流程定义独立成表 + 引用改绑，并需为在途单快照补「模板版本」维度。
- 跟进：00 号 §5 拍板点 2 标 ✅（已回写）；06 号 B2 波接入 `template_code` 前端。
