> **当前状态与入口**：通用大屏独立后置，尚未实施；重启需要业务数据积累与明确受众双条件。它与[Phase6 R4](../phase6/04-r4-metrics-reports.md)风险域看板是两种消费场景，已拍保持独立，不互相吞并。先读触发/不做范围，不预建空页面、目录或通用报表引擎。

> **段属性**：**条件段（🚦 触发驱动）**——所有者明示后置（当前业务数据量少）；**不计入 phase5 收口**，触发即启动。
> **文档定位**：薄设计稿（2026-10-15 建档，phase5 分支）。立项 = dd §27（2026-10-08 第五轮）。

## 1. 定位

业务数据大屏展示——**只读展示层**（工作台增强或独立大屏页），零业务逻辑。

## 2. 触发条件

phase5/phase6 各模块产生**真实业务数据** + **明确展示受众/场景**（两者同时满足；任一缺则为无源之水——数据量少时大屏 = 空壳）。

## 3. 范围概要

- 展示源 = 工单/任务/风险（phase6）等各域既有统计能力（工单聚合统计端点候选已在 phase4/02 P4-8 候选登记——触发驱动，届时一并收编）。
- echarts 已在 zhuzhao-ui 依赖在档，零新增前端基建。

## 4. 量级

触发后 ~1 周（纯展示；数据聚合端点若需新增另计）。

## 5. 边界（不做）

不做实时推送（轮询/既有刷新足够，随触发批重估）；不做自定义报表引擎（§23 域不碰）。
