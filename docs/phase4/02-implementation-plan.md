## 1. 主轴拍板（按 00 号 §7 建议组合）

| 线 | 定位 | 理由 |
|----|------|------|
| **① 产品完整线** | **主动线** | 前端 zhuzhao-ui 是唯一无外部前置、运营杠杆最大的件（裸 API 的 IAM 是运营硬伤）；线内其余项（通知/字典/导出/验证码/PAT/MCP）均可独立成批穿插 |

| **⑤ 工单翻案线** | **挂起** | 等 §23 翻案条件；类型可见性策略 S1 设计输入已在 10 号 §10 备好 |
