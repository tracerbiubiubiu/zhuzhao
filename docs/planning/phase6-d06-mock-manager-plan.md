## 范围与数据边界

`resolve-manager` 接收一名已登记合成员工和一条直属主管外部引用。员工和主管都须通过同一模拟作用域、有效身份世代与同租户检查。仅观察已登记事实。主管尚未登记时持久保存外部引用和待解析回执；绑定晚到后，用新的操作号提交原引用补解。引用已失效或指向本人时给出可辨认结果。原操作同号同内容返回最初回执。另一个进程可用 `manager-receipt` 查询。

沿用迁移 `000098` 的员工绑定及操作回执表。主管操作使用批次和调动标识不能表达的内部操作键，与调动回执隔离，保留既有调动的存储键及 JSON 格式。调动的来源修订、账号、角色、组织任职、负责人和派单历史继续由各自的现有写方管理。
