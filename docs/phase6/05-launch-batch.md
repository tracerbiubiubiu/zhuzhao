# 05 — P6 启动批总账（Week 0 基建件 + 尾款随行）（设计稿）

> **文档定位**：启动批账本（2026-10-26 建档）——把散在 [README §7](README.md)、[00 号](00-flow-engine-v2.md)、[债台账 B 组](../phase5/S6-S5-debt-ledger.md) 的启动批内容收拢成一张总账。**启动批 = 立项动作 → 本批基建 → R1 开工**；全程**不进核心切片计时**（D25「核心 6 周守住」从启动批出口起算）。

## 1. 启动批构成（三层）

### 1.1 立项动作

X1 漏扫契约获取（外部第一动作——首源适配器与 DoD 的阻塞输入）/ T1 核心清单拍板落档 / 切 `phase6` 分支 /〔待立项〕[00 号 P6-R0 流程引擎 v2](00-flow-engine-v2.md) 批准与 ADR-004（00 号 §5 拍板点 1–2：本段若立项则替代「直接开风险模块」，风险首件业务顺移 ≈2.5–3 周换处置执行面流程能力到位）。

### 1.2 Week 0 基建四件（2026-10-26 所有者拍板）

| 件 | 量级 | 出口贡献 |
|----|------|---------|
| R3 前置待建四件（prefill 端点 / params 泛化 / external_http 适配器 / DataFetcher 超时·限流·审计） | 3–4 天 | 接入地基（R3 接真实外部源前必须；11 号 §1 既定） |
| HR 目录接口 mock 先行 + S3a 指派轴扩充 | 2–3 天 | 指派地基（R1 owner 指派 / R3 按部门负责人·直接上级分派；真实 HR 到位=换 adapter；[hr-directory-sync](../proposal/hr-directory-sync.md)） |
| BK-21 护栏泛化 | 1–2 天 | L2 地基（risk_items 接 L2 的 fail-closed 哨兵泛化） |
| mock IdP（可选随行） | ~1 天 | UAA 离线验收地基（A5 既定） |
| **合计** | **约 7–10 天** | **出口标准 = R1 正式开工时，接入/指派/L2 三块地基全绿** |

### 1.3 phase5 尾款随行（B0-1 圈范围时统一定序重锚）

- 工单×任务接缝三件：**B-20** spawn_task `from:ticket.field` 入参映射（与 [03 号 §3.3](03-r3-ticket-linkage.md) 映射语义合并设计）/ **B-21** 转换级 meta 前端配置面（范围随 S2 走查结论门控：基础档 vs 设计器整合批）/ **B-8** `run.succeeded` 反向链（工单触发任务闭环）。
- S6/S5 债小件（B-1/2/3/16 等）——清单见 [债台账 B 组](../phase5/S6-S5-debt-ledger.md)，原「B6-7 二期」锚已失效，圈范围时统一重锚。
- A-6 transition_meta 丢配置修复（P1）**不等的**——已随 phase5 走查批先行销账（24920b3）。

## 2. 依赖硬约束（仅三条，其余并行/串行由圈范围定）

1. **B0-3（定义快照）先于 B0-4（自动路由）**——[00 号 §4](00-flow-engine-v2.md)：自动流转不能跑在会变的定义上；
2. **BK-21 先于 R1**——risk_items 是第一个新接 L2 的资源，哨兵泛化必须先行；
3. **R3 前置四件先于 R3**——接真实外部源前的加固件。

## 3. 不锁启动批（明确出清）

- **登录/登出审计（~0.5 天）**：清单中唯一「当下即缺口」件（`/auth` 匿名组现零审计——ISO 27001 A.12.4 拷问点），零依赖、不依赖本模块，随 phase5 收官后**任意小批随时捎带**；
- **S3b 审批引擎**：等首个真实审批场景；蓝本 = dd §29「任务行展开」（外部平台勘查收口：引擎只持图状态、一行=节点×办理人、退回取历史办理人、撤回三条件、probe 防死循环）；
- **统计 DSL / 版式报告二三档**：触发驱动（[04 号](04-r4-metrics-reports.md)）；
- **SSE / 存储第二 driver / UIP 通道差距 / AI 目录**：各自域触发登记（README §7 总账）。

## 4. 准入门槛（防启动批范围膨胀）

不依赖 phase6 范围拍板 ✚ 不依赖外部契约 ✚ 有独立价值或是 phase6 硬依赖 ✚ 单件 ≤4 天——**四条全中才进**。
