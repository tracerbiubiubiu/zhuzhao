- 从已合入规划的最新五仓main核实际HEAD，再为每个写任务建独立worktree；不能继续把旧审计分支当未来实现基线。准确五仓SHA/公共库版本/协议/迁移/工具链写入候选manifest，缺companion revision不静默回落main。

- 迁移开工当天核磁盘与控制台下一编号，本文不预占000082或其它号码。up/down成对，遵B案回滚代码/DB耦合；接口/权限同步Swagger、目录绑定、UI生成物和模块说明。

- 本轮已有原则（mock保留、专业供给优先、模型仅API、内网只内部模型、私有adapter隔离、设备人工入口）不再重拍。owner当前决定只对其明确范围生效，不推定全部后期能力已批准。B06/B07已确认批准映射逐项自动交接、预览确认撤部plan后批量处理；具体映射/plan仍需合法批准，不代表已执行HR变更。
