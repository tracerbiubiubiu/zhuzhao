## 3. 核心切片（已确认模块）

1. **扩源两适配器**：SOC 告警 + 日志平台告警各一（webhook 推为主、http-pull 兜底）；归一 schema 扩到 `security_alerts`（03-A8），与 findings 共用指纹与聚合语义——**R5/D30 的告警管道即此件的延伸**。
2. **路由规则 + 维护窗口**：expr-lang 匹配 → 建风险单 / 挂既有 / 通知 / 抑制。
3. **告警聚合视图**：按资产 / 类别 / 源。
4. **Action 注册表**（03-A1）：统一 Action 抽象落地，存量 handler（audit_archive 先例）宽松迁入。
5. **service account + 委托三元组**（03-A6）：非人身份 + 审计标记。
6. **调度分工收敛**（D18）+ cronloop 分布式锁 + 一次性延迟任务。
7. **资产查询门面**（02-G1 / D29 前置批）：查询连接器 + 统一解析门面，读穿缓存可选——不自建资产台账（D4）。
8. **运行可观测 M4**（09 号补强）：Prometheus 暴露格式 + OpenTelemetry 语义 + `trace_id` 贯穿 taskrunner→sandbox-runner→回调 + 计划任务总览只读视图（防 CronScheduler/taskrunner 双轨割裂）。
9. **on_success 轻编排钩子**（08 号 P4）：回调串联最小形态。
